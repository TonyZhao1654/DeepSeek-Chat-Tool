# DeepSeek-Chat-Tool
声明
这只是一个个人用的小工具，没有安全性可言
代码写的也不好，我就是个学生



使用方法：
1.把自己的deepseek api复制到根目录的api.txt文件中
2.在backend/main/下有main.exe，双击可直接运行
可以给main.exe创建快捷方式
可以自己修改源代码，然后自己build一个exe程序



功能十分有限
可以使用deepseek api可以进行接近网页端的对话
同时支持添加内容块来避免反复粘贴代码
不能撤回消息，不能修改消息，不能发文件（图片也不行）
只能进行纯文字对话



根目录下的data文件夹是本地数据库文件
